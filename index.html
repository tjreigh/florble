    Daily puzzle

    How Daily works

    Find the hidden five-letter word. The symbols are arranged like a QWERTY keyboard, so each one stands for the letter in that familiar position.

    1. Each symbol always stands for the same letter.
    2. Every letter has its own distinct symbol.
    3. You can click the symbol keyboard or type on your physical keyboard.
    4. Symbols can be reused, so words with repeated letters work normally.
    5. After each guess, the tiles show which letters belong in the answer.

    Feedback and overtime

    You get six guesses for the official score. If you do not solve it, overtime keeps giving you another guess. After a while, it also reveals letters to help you finish.

    • ✓Right spot — the letter is exactly where it belongs.
    • ◇Wrong spot — the letter is in the answer, but elsewhere.
    • ×Not used — the answer does not contain that letter.

    Clues never change or hide what you entered.

    Accepted words

    Florble accepts a broad dictionary. If a word is not accepted, it does not use up a guess.
